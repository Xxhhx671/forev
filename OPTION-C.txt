FOREV — вариант C (без Volume на Railway)
==========================================

Без Volume SQLite на Railway не переживает деплой.
Рабочий процесс:

1. Админка → Форум → Настройки → «Скачать бэкап БД»
   Сохрани .db файл у себя (телефон / облако / Telegram).

2. После деплоя или если база пустая:
   Админка → Форум → Настройки → «Восстановить из файла»
   Выбери сохранённый .db → сервер перезапустится.

В бэкапе есть: аккаунты, хеши паролей, ключи, форум, чат, настройки.

Рекомендации:
- Скачивай бэкап перед каждым деплоем
- Держи 2–3 последних файла
- Не полагайся на папку backups/ на сервере — без Volume она тоже пропадёт

Запуск локально:
  node server.js
  → http://localhost:3000
